HOW TO PUBLISH THE NEXT S5 STUDIO VERSION

EASIEST METHOD
1. Put your newly built EXE inside this repo's /downloads folder.
2. Open PowerShell in the repository folder.
3. Run:
   .\tools\Publish-S5-Update.ps1
4. Enter the new version, for example 5.2.0.
5. Select/paste the path to the new EXE.
6. Enter release notes separated by semicolons.
7. The script copies the EXE, calculates SHA-256, and rewrites app-version.json.
8. Commit/push the changed files to GitHub.
9. Everyone's S5 Studio will see the update on the next Check Update/startup check.

DO NOT delete old EXEs immediately if users may still need them. app-version.json only points at the current latest one.
