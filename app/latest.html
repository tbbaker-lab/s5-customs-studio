Studio updates

S5 checks your GitHub Pages app-version.json. The launcher stays installed; Studio code updates in place from GitHub and then restarts. No duplicate EXE is downloaded.

How it worksWhen a Studio update is available, S5 refreshes the hosted app from GitHub, installs any required asset packs, then restarts into the new version. The permanent launcher EXE is not duplicated.
